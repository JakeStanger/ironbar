%properties:CommonConfig%

## Truncate Mode

Many modules have a `truncate` option (or variants),
used to control how text is cut down when it is too long to fit the container.
These all use a common type, defined below.

If both this and a marquee mode are set, this takes precedence.

%properties:TruncateMode%

## Marquee Mode

Some modules also have a `marquee` option, which can be used instead of truncate
to scroll text that does not fit.

If both this and a truncate mode are set, the truncate mode takes precedence.

%properties:MarqueeMode%
